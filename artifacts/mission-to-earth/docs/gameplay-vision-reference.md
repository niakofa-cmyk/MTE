## Direction for this project

### Core experience

- A cinematic, story-driven first-person shooter set in the occupied Earth
  district of Nod.
- The Accord sends four warriors—two Dharma and two Ma'at—to rescue Ananda and
  Nefret, recover Eon Dusk intelligence and technology, build a local
  resistance, activate the beacon, and extract.
- Combat should reward aim, movement, sound awareness, positioning, teamwork
  with allies, and use of destructible cover.
- Loot, equipment customization, survival pressure, and extraction should add
  choices to the mission rather than replace its story.
- Meaningful discoveries and outcomes should let the world respond to player
  actions. Extracted Eon Dusk plans can reveal the wider threat against Mars.

### Apply the vision incrementally

- The current game is a bounded Nod mission, not a completed open-world
  campaign. Deepen and verify its existing routes, combat, allies, mission
  pacing, loot, and extraction before increasing map size.
- Preserve the current single-player mission and NPC allies as the foundation.
  Do not treat requests for 6v6, PvP, co-op, a large battle royale, or an MMO
  loot loop as authorization to add networking or a new game mode now.
- Defer streamed regions, vehicles, and large-scale multiplayer until the
  playable region, navigation, collision, performance, and campaign progression
  are reliable.
- Adapt genre references as design inspiration; do not copy another game's
  identity or claim unfinished features are complete.
- Keep player-facing terminology consistent with `NARRATIVE.md`; preserve
  existing save identifiers unless a tested migration is planned.

### Current implementation connection

The code already has four operators, two rescue sites, a local uprising, the
beacon-and-extraction sequence, randomized loot, an active zone, allies, and
weapon customization. Use these existing systems as the base rather than
building parallel versions. The mission epilogue now distinguishes a run that
extracts Eon Dusk blueprints from one that leaves that intelligence behind.
